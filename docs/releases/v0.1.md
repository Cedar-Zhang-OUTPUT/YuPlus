# Yu+ v0.1

Yu+ 的第一个正式版本：在 Codex 中与 Agent 协作，在本机保存项目材料、对象、来源和修改历史。首版面向 macOS，支持信息收集（draft）与信息整理（review）两个可往返的场景。

## 开始使用

下载本 Release 附件 `YuPlus-v0.1.tar.gz` 与 `SHA256SUMS.txt`，放在同一目录，执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
tar -xzf YuPlus-v0.1.tar.gz
cd YuPlus-v0.1
./install.sh
```

也可以把官网的完整安装提示词发给 Codex，让 Agent 完成安装和启动。

统一入口准备合适的 Python/SQLite 运行环境，安装 CLI 与两份 Codex Skill，初始化正式数据目录，并检查飞书 CLI 的认证状态。缺少飞书时仍可处理本地文件与口述材料；不会自动登录或安装飞书 CLI。

默认数据目录：`~/.local/share/yuplus`。安装完成后：

```sh
~/.local/share/yuplus-app/venv/bin/yu start --json
```

在 Codex 内置浏览器打开返回的实际 URL。再次使用 `start` 会复用已核验的服务；`status` 查询地址，`stop` 停止托管服务。可显式设置安装与数据目录，现有项目不因重新安装而清空。

## 本版功能

- 多项目、飞书/本地/口述来源、不可变来源快照与版本。
- 23 类 draft 业务对象、基于来源和依赖组织的 review 成果，以及共享 Q&A。
- 强制先修改 draft 再更新 review，保留变更与决策历史。
- 本地只读可视化界面，真实项目、材料、关联对象与版本追溯。
- 数据库及材料文件的完整备份、校验与恢复。
- 启动时飞书来源版本检查，CLI 与页面提示远端更新，由 Agent 同步相关内容。
- 两份按需读取的 Codex Skill：项目协作和可视化浏览。

## 验证与范围

应用提交：`3db434a`。120 项后端测试、29 项前端测试、94 项契约检查通过；已演练本机安装、服务复用、备份恢复及真实飞书更新检查。两份 Skill 校验通过。

首版面向 macOS。本地保存不等于离线 AI：Codex 和飞书读取仍依赖相应服务。后台只检查来源，不自动改写项目。真实 Agent 使用验收及跨机器分发/升级验收将在发布后进行。
