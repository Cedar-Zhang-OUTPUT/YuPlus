# Yu+ v0.2.1

本版修复本地材料标题的打开行为，并纳入实际使用测试中对 Yu+ Skill 的优化。

- 点击本地材料的文件名，直接在新标签页打开所引用版本的原件；PDF 可直接阅读。“查看引用”继续打开来源记录。
- 优先使用原始文件，不将提取文本或预览图当成原件。原件缺失、已变化或多文件来源无法唯一定位时，进入该版本的文件详情；不会跳到另一个版本冒充原件。
- 客户 Q&A 只收录需客户回答、对项目有实际影响的业务问题。内部行动、内部选择和测试/操作问题分别处理，不把所有未知内容自动变成客户问题。
- 区分材料的业务时间和当前处理时间，避免把历史日期自动理解成逾期、改期或已完成。
- 同步对象目录、正式 Skill 及中文审阅稿。中文审阅稿仍不安装，也不供 Agent 自动读取。

## 安装与升级

从[官网](https://cedar-zhang-output.github.io/YuPlus/)复制短提示词给 Agent，按官网安装指南下载 `YuPlus-v0.2.1.tar.gz` 并验证 `SHA256SUMS.txt`。

支持 macOS，Python 包版本为 `0.2.1`。升级前完成备份并停止旧服务，沿用原应用、项目数据与 Skill 目录安装，再启动服务。修改过的非托管 Skill 不会被强行覆盖。v0.2 → v0.2.1 不增加数据库迁移，仍为 schema 2；项目、来源与历史记录保持不变。

## 验证

160 项后端测试、45 项前端与官网测试、94 项契约检查通过。使用隔离项目和合成 PDF 验证收录、draft 引用、标题点击、新标签页原文渲染；已在 Codex 内置浏览器看到 PDF 正文。

Skill 的实际 Agent 行为回归仍由用户测试，不将格式与契约检查当作行为验收。未读取真实群聊、创建真实定时任务或改写用户项目数据。
