# Yu+ v0.2.2

本版修正附件保存操作，以及收集场景中的下一步引导。

- 文件池中的附件显示“下载”，按登记的原文件名和扩展名保存原字节，包括口述来源附带的图片和备份恢复的文件。保留“打开文件”预览。
- “在 Finder 中显示”只用于 macOS 上仍可核验的外部登记原文件；不再选中内部哈希命名的存储文件。服务端也拒绝用定位接口打开文件池副本。
- 收集后同时给出两个选择：继续补充/澄清具体材料与对象信息（说明用途、提供方式），或根据现有信息开始相关 review 整理。取消每次上传后默认推荐 Debrief 的示例。
- 不凭空制造缺口、不反复催问已答或已推迟的问题，不把补充资料变成进入整理的门槛。用户已选择整理时直接执行，不再让用户二次选择。
- 同步正式 Skill 和中文审阅稿；中文稿仍不安装、不供 Agent 自动读取。

## 安装与升级

从[官网](https://cedar-zhang-output.github.io/YuPlus/)复制短提示词给 Agent，按安装指南下载 `YuPlus-v0.2.2.tar.gz` 并验证 `SHA256SUMS.txt`。包版本 `0.2.2`，支持 macOS。

升级前备份、停止旧服务，沿用原应用/数据/Skill 目录安装，再启动服务。数据库仍为 schema 2，无新增迁移。已有项目与附件不需要重新收录；修改过的托管 Skill 仍按安装器冲突规则处理。

## 验证范围

使用隔离项目模拟“用户口述附四张图片”，在 Codex 内置浏览器确认四个附件均显示下载，并实际点击下载：原文件名、扩展名和文件字节一致。测试覆盖 Finder 外部原文件定位、文件池/恢复副本拒绝定位、原名下载、项目隔离及原有内联预览。

Skill 的格式与引用检查不替代真实 Agent 行为验收；新版下一步引导仍需实际项目对话验证。未使用真实群聊、创建定时任务或修改用户项目数据。
