# Yu+ v0.2

本版增加飞书项目群监控。用户在 Codex 明确指定项目与群后，Agent 可通过原生定时任务持续收集进展，默认每60分钟检查，按用户要求调整间隔。

- 首次收集当前身份可访问的全部历史与已发现话题，按时间顺序分批建立项目理解。
- 后续增量读取、消息版本去重、固定窗口续读、执行租约与业务步骤回执，避免中断后重复添加决定。
- 群消息保留为可追溯来源，先维护 draft，再更新已有受影响 review；决策历史持续保留。
- 项目列表及 draft/review 展示监控群、历史覆盖、检查与同步结果；页面保持只读和现有风格。
- 同步两份正式 Skill 和中文审阅稿；中文副本不安装、不由正式 Skill 引用。

## 安装与升级

官网：https://cedar-zhang-output.github.io/YuPlus/

复制官网短提示词给 Agent，或下载本 Release 的 `YuPlus-v0.2.tar.gz` 和 `SHA256SUMS.txt`：

```sh
shasum -a 256 -c SHA256SUMS.txt
tar -xzf YuPlus-v0.2.tar.gz
cd YuPlus-v0.2
./install.sh
```

支持 macOS。GitHub 版本名为 v0.2，Python 包版本为0.2.0。安装包只包含应用及配套文档，不含官网部署目录或用户数据。

从 v0.1 升级前，用旧安装记录中的 CLI 和真实数据目录完成 `backup create`、`stop`，再沿用原应用前缀运行安装入口。升级保留项目、来源和决策；首次访问旧库时执行数据库迁移并创建迁移前完整备份。已有服务不会自动重启，安装后必须重新 `start` 并核验服务身份。不要把旧版本程序直接用于已迁移的库；需回退时，将升级前备份恢复到新目录。

修改过或非托管的 Skill 不会被安装器直接覆盖。Python/SQLite 不合适的旧虚拟环境不会被自动重建；保留旧安装，按官网 Agent 指南选择新应用前缀并沿用原数据与 Skill 目录。

## 验证与边界

160项后端测试、40项前端与官网测试、94项既有契约检查通过；完整 CLI→SQLite→HTTP→draft→review 链路使用模拟飞书接口验证，独立代码复查问题已修复。

真实群聊权限与真实定时任务由用户发布后验收，本次未创建任何真实监控任务。定时唤起依赖 Codex 原生工具及本机可用状态；没有宿主定时能力时可手动同步。电脑休眠、离线或关闭 Codex 时不保证运行。CLI 记录调度回执，Agent 需用宿主工具核验实际执行身份和任务范围。

历史范围限于 API 可访问内容；不保证发现所有迟到消息、很旧且未被引用消息的编辑或此前不可见的话题。无法读取的附件不算已读，缺失消息不直接推断为撤回。群监控不向群发送消息，也不编辑飞书原文。
