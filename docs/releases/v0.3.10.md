# Yu+ v0.3.10

修正长对象标题栏结束吸顶的时机：对象底部刚进入屏幕后，继续向下滚动，标题立即随内容等距离上移，不再等到整个对象快滚出屏幕才离开。

- 适用于信息收集对象与 Review 成果。
- 能在当前阅读区域完整显示的短对象正常随页面滚动，不额外吸顶。
- 保留顶部导航和堆叠目录避让，版本切换后重新测量标题高度。
- 使用原生 sticky 布局处理滚动，避免滚动时通过脚本切换固定定位。
- 无数据库迁移，沿用现有项目、材料及监控配置。

验证：56 项前端与官网测试通过；内置浏览器验证底部进入屏幕后标题等距离上移、短对象正常滚动及历史版本切换；隔离环境从 v0.3.9 升级，验证数据保留、Skill、服务及前端资源。
