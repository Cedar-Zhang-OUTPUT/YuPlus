# Yu+ v0.3.17

- 飞书导出改为供人阅读的 Review 成果文档：保留固定章节与事实，在相关位置引用云文档、会议纪要，按需上传本地附件和原始案例图片；排期可采用多维表格甘特图，能力不足时使用可读时间表。
- 内部导出包只供 Agent 核对，禁止将日志、ID、file key、依赖 JSON 和完整溯源附录原样写入飞书正文。主 Skill、按需参考、中文版与页面短 Prompt 同步更新。
- 导出回执摘要对应最终发布稿；仍需远端回读核验后登记，保留实际导出版本与历史记录。
- 导出历史按钮缩小为与左侧按钮居中对齐的小图标；案例库「复制移除 Prompt」采用红色。
- 数据库保持 schema 4，无新增迁移。

升级请从[官网](https://cedar-zhang-output.github.io/YuPlus/)复制提示词交给 Agent。升级前备份并停止旧服务，沿用原数据目录，安装后重新启动。两份英文 Skill 随安装更新，中文副本仅供人工审阅。安装包与 SHA256SUMS.txt 配套校验。

验证：前端/官网 68 项、后端 203 项测试及两份 Skill 结构校验通过；发布包隔离安装与内容一致性校验通过。本轮未创建真实飞书文档，真实导出呈现待实际使用验证。
