# Yu+ v0.3.18

修正飞书导出 Skill：只要“时间节点或区间”包含具体日期或完整区间，文档对应章节内就必须显示甘特图，不能用普通表格、文字列表或单独链接代替。

- 纳入范围内全部有日期的节点与完整区间，节点用里程碑、区间用时间条，保留精度、时区与待定标记。
- 可使用文档内可见的多维表格甘特视图；无法嵌入时，使用飞书 Mermaid 甘特图画板。
- 回读并检查实际渲染。图表未完成或未核验时不登记导出成功；没有可定位日期时明确说明，不编造日期。
- 主 Skill、导出参考及中文审阅版同步更新。数据库仍为 schema 4，无新增迁移。

从[官网](https://cedar-zhang-output.github.io/YuPlus/)复制安装提示词即可升级。升级前备份并停止旧服务，沿用原数据目录安装后重启。升级后重新读取新版 references/export.md，避免沿用旧会话中允许退回普通时间表的指引。

本次为 Skill 规则修正；完成 Skill 结构校验、官网检查和发布包校验。本轮不创建真实飞书文档，实际导出效果需在使用中验证。
