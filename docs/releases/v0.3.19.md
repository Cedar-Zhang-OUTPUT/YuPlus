# Yu+ v0.3.19

案例库源新增网站类型，所有项目共用。

- 新增区域提供“飞书共享文件夹”和“网站”两条独立的链接输入及复制 Prompt；各自填写有效链接后才允许复制。
- 卡片标明类型，以可点击标题在新标签页打开原站点；保留红色移除 Prompt。
- CLI 的 library add/update 支持 kind=feishu_folder 或 website，兼容旧文件夹输入。网站支持 HTTP(S) 链接；删除与恢复均仅操作本地登记。
- 网站按需通过浏览器/网页工具查找，飞书共享文件夹仍使用飞书 CLI。程序只登记类型、名称与链接，不保存案例正文、附件或搜索索引。英文 Skill 与中文审阅版同步。
- 升级至 schema 5：旧案例库登记自动标为飞书共享文件夹，保留项目、登记 ID、版本和历史；迁移前自动完整备份。

升级前请备份并停止旧服务，沿用原数据目录安装后重启；需要回退时，将升级前备份恢复至新目录，不能让旧版程序直接读取 schema 5 数据库。官网安装提示词与 Agent 指引同步更新。

验证覆盖两种源的新增、读取、修改、重复链接校验、删除/恢复、备份恢复、旧库迁移及前端输入/复制；真实网站的查找由 Agent 在使用时执行，本次不抓取案例内容。画板预览 ADR 保留为后续找案例功能的设计决定，本版未实现画板预览。
