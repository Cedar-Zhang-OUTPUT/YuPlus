# Yu+ v0.3.2

修复点击暂无内容的 Review 类别后整页空白的问题。

空类别渲染中残留了不存在的辅助函数调用，导致页面渲染中断。现在选择尚未生成的创意审查结果、内外部创作者 Brief 等类别时，标题、监控面板及五类成果导航正常保留，主内容区显示简短“尚未生成”空状态。可直接点击另一类别查看已有成果，无需重新进入“整理与 Review”。

本次不改变业务数据、数据库 schema 3 或 Skill 行为，沿用现有界面样式。

## 安装与升级

从[官网](https://cedar-zhang-output.github.io/YuPlus/)复制安装提示词给 Agent，升级到 v0.3.2（包版本 0.3.2）。升级前备份并停止旧服务，沿用原数据目录安装并重新启动，然后刷新页面。

## 验证

56 项前端与官网测试通过，新增覆盖四类可生成成果的空状态及从空类别直接切回已有成果。Codex 内置浏览器通过真实本地服务验证“已有推进要素 → 空创意审查结果 → 空创作者 Brief → 已有推进要素”，页面和导航全程保持可用。使用隔离模拟项目，未改用户正式项目。
