# Yu+ v0.3.20

找案例已接通真实飞书画板链路，同时加入工作空间头像更换。

- 新增独立“找案例”页面：研究历史 v1/v2、秒级创建/更新时间、画板缩放/平移、适应窗口及飞书新标签页跳转。
- `research create/update/list/show/preview` 保存研究元数据与定位。新研究分配新版本，同轮补图、修改说明和飞书直接编辑沿用同一画板；重复请求不重复建轮次，不允许不同研究共用同一块画板。
- Agent 按 Skill 用飞书 CLI 创建和更新画板；预览由本地服务自动获取，当前可见板每 60 秒刷新，失败保留旧图，认证/权限错误暂停。临时缓存不进入业务数据或备份，不创建 source/draft/review。
- 找案例 Skill 明确案例库检索、公共网络补充、真实案例图、飞书证据索引，以及新轮次和同轮修改的区别；英文执行版和中文审阅版同步。
- 左上角头像菜单复制更改提示词，Agent 压缩后通过 `logo set` 应用，支持读取和重置。
- schema 7：迁移前自动完整备份，保留现有项目和历史；安装包包含前端、CLI 和两份 Skill。

升级前先备份并停止旧服务；沿用原数据目录安装后重启，确认 doctor 的 schema_version 为 7。旧程序不能直接读取迁移后的库，回退需恢复升级前备份到新目录。官网安装提示词与 Agent 指引同步。

已在独立测试项目验证真实飞书图片写入、同轮追加、自动预览、版本切换、新标签页跳转及备份恢复；Python 215 项、前端 80 项测试通过。案例内容仅保存在飞书；图片预览不提供画板编辑，编辑请跳转飞书。
