# Yu+ v0.3.22

官网与应用使用更贴近创意策划工作的语言，保留现有设计与操作方式。

- 官网以「更懂人，才更动人。」为主标题，更新产品介绍、功能说明与项目演示对话。安装细节和演示命令收进可展开说明。
- 统一「项目信息」「策划文档」「案例分析」「原始资料」「信息分类说明」「修改与确认记录」等栏目名称。
- 更新空白页、信息性质标签、复制指令和受影响内容提示；保留补充资料与先整理一版的选择。
- 文档名称改为「项目推进安排」「创意评审记录」「创作者 Brief」，客户 Q&A 继续包含已答复的问题。
- Skill 与中文审阅版同步新名称；明确当前案例图集为「案例参考板」，飞书文档按用户请求生成，不自动持续同步。

CLI 命令、数据类型键、策划文档固定结构和数据库 schema 7 不变。已有项目可沿用；升级前按安装指南备份并停止旧服务，安装后重新启动。
