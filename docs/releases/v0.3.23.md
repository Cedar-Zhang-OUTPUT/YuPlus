# Yu+ v0.3.23

完善排期与客户问答信息，精简对象目录，并提供随安装初始化的案例库源。

- 时间节点或区间增加可选 `owners` 数组，支持空、单人和多人；甘特图标题旁以灰色小字显示负责人，详情显示完整名单。
- 客户 Q&A 分开显示提问人和回答方；跟进人继续独立记录，未知身份不从旧文本自动推断。
- 信息分类说明从左侧导航移到「项目信息」标题旁的问号入口。
- 从当前对象模型、CLI、前端、导出及 Skill 中移除 D16 立项评估结果与 R04 创作者 Brief；当前提供 23 类业务信息。其他对象编号保持稳定。
- 内置 18 个已确认案例库源（1 个飞书共享文件夹、17 个网站），随 CLI 安装初始化。每个工作空间仅登记一次，按链接复用已有记录，包括已移除记录；不覆盖用户修改，不重新添加已移除来源。仅保存登记信息，不下载案例内容。
- 中英文 Skill 与官网安装指引同步更新。

数据库升级到 schema 8。升级前请备份并停止旧服务，再沿用原数据目录安装、启动。程序迁移 schema 1–7 前还会自动完整备份；旧对象的不可变历史与引用保留用于追溯，不能恢复为当前可用对象。案例库初始化记录随备份保存，恢复后仍尊重用户修改与移除。

验证：221 项 Python 测试、79 项前端/官网测试通过；完成打包安装、默认案例库登记、重复启动、去重、改名/移除保留与备份恢复检查。
