# Yu+ v0.3.24

策划文档接入飞书协作链路，并按目录顺序统一对象编号。

- 新增创意方案与创意评审/反馈信息，方案与反馈保留具体方向、原始版本和来源关系。
- 策划文档使用固定结构：主策 Debrief、项目推进安排、创意方案、创意评审记录及共用客户 Q&A。
- 用户进入策划文档场景时，Agent 保存本地成果并创建或复用飞书协作文档；页面常驻新标签页跳转链接及同步记录，移除单独复制导出入口。
- 新增 collab 命令：文档绑定、变化收录、三方比较、冲突解决、按章节回写及调度绑定。飞书变化必须先进入 draft，再更新相关 Review。
- 本地服务每 60 秒检查已绑定文档；Agent 自动整理需要实际宿主任务，建议五分钟并遵守宿主能力和用户设置。安装升级不会替用户创建新任务。
- 同一章节两端都修改时要求明确选择；写入核对两端版本。对可能丢失评论或素材的章节保留原内容、暂停自动替换。
- 信息目录连续编号 D01–D25，策划文档 R01–R05；内部类型键、对象 ID 和历史关联保留。项目导航使用 1、2、3。
- 英文 Skill、中文审阅版及官网安装指引同步更新。

数据库升级到 schema 9。升级前备份并停止旧服务，沿用原数据目录安装后重新启动；程序迁移 schema 1–8 前会另存完整备份。恢复备份后协作文档观察暂停、调度回执清空，核实实际宿主任务后再绑定。

验证：239 项后端测试与 73 项前端测试通过。真实飞书已验证创建、远端变化回流、draft→Review 因果校验、局部回写、重复变化去重及同节冲突拦截。多人编辑通过同一测试账号模拟不同修改顺序；真实多账号与宿主定时唤起由实际使用继续验证。
