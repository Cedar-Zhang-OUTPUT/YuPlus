# Yu+ v0.3.25

新增本地硬删除，并为策划文档提供开始整理的复制指令。

- 新增 `project purge`、`draft purge`、`review purge`、`source purge`、`library purge`，覆盖整项目、单个对象、原始资料及案例库登记；原有软删除与恢复功能保留。
- 硬删除默认只预览，显示删除范围、引用阻塞、文件数量及关联宿主任务。执行需要匹配的目标 ID、预览计划摘要、原因和稳定请求 ID；计划变化时拒绝旧请求。
- 当前及历史引用都会保护关联内容。整项目删除清除项目历史、无人引用的材料副本和画板预览缓存；共用文件、外部原件、飞书内容与已有备份保留。
- 有实际定时任务时须先停止任务；有效同步租约会阻止删除。文件清理失败返回待清理项，同一请求可继续重试。保留最小删除与幂等回执；不承诺取证级磁盘擦除。
- 策划文档的“飞书协作文档”空状态新增“复制开始整理指令”，携带真实项目与数据目录，按 Skill 生成适用成果并建立或复用协作文档；点击仅复制，不直接执行。模拟页面不会引导写入真实项目。
- 英文 Skill、中文审阅版、官网短提示词及 Agent 安装指引同步更新。

数据库升级到 schema 10。升级前备份并停止旧服务，沿用原数据目录安装后重新启动；程序迁移 schema 1–9 前会另存完整备份。安装升级不会执行硬删除或创建协作文档。

验证：254 项后端测试通过，覆盖迁移、引用阻塞、共享文件保护、事务回滚、监控与协作记录清理、预览缓存清理及重试；73 项前端测试通过。所有破坏性测试使用临时数据，未删除用户项目。
