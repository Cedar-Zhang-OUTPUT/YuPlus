# Yu+ v0.3.5

新增项目重命名。用户可在 Codex 对话中要求 Agent 为已有项目改名，Agent 通过 `project rename` 执行，前端刷新后显示新名称。

- 使用原项目 ID，保留材料、draft/review、群监控、来源关系及历史。
- 记录新旧名称；校验 `metadata_version` 防止覆盖并发修改，重复请求幂等，同名修改不增加版本。
- 正式 Skill、CLI 参考、中文说明已同步，前端继续保持只读。
- 数据库仍为 schema 3，无新增迁移。

命令：`yu --data-dir DIR project rename --project ID --name '新名称' --base-version N --request-id REQUEST_ID --json`。N 使用 `project show` 返回的 `metadata_version`。

升级可从官网复制提示词交给 Agent。升级前备份，沿用原数据目录并停止旧服务，升级后重新启动、刷新页面。

验证覆盖 CLI 完整来源/draft/review 链路保持不变、服务即时读取新名称、持久化、版本冲突、请求重放、非法输入及归档项目保护；另完成全量自动测试和发布包原位升级检查。
