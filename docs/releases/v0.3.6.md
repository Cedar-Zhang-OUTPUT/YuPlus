# Yu+ v0.3.6

修复飞书群聊首次历史同步因消息时间形如 `2025-12-11 14:52` 而中断的问题。读取适配器与监控入库共用时间解析器，兼容本地分钟/秒格式、带时区 ISO 时间和毫秒时间戳；消息编辑时间与话题回复使用相同规则。

飞书 CLI 的无时区显示时间使用进程本地时区；Yu+ 按同一时区解析（使用历史日期的时区规则），统一以 UTC 保存排序值，保留来源原始文字。分钟输出不添加虚构秒级精度。无效日期仍报错并保留断点，不会当作空消息页继续。

升级后继续原监控与原运行；仍有效的租约可继续 fetch，过期后重新 begin 恢复运行。无需删除群绑定或重新导入已保存历史。Skill 及中文恢复说明已同步。数据库仍为 schema 3，无新增迁移。

验证包括混合时间格式、本地时区与夏令时、消息编辑时间、话题回复、首次历史分页中断/续读、重复同步去重、完整 draft/review 链路及安装包升级。外部飞书使用模拟 CLI；真实群聊和宿主定时触发未作为本次验证结果。

升级请从官网复制提示词交给 Agent：备份、停止旧服务、原位安装，沿用原数据目录，重启服务后继续未完成监控。

格式依据：[飞书 CLI FormatTime 实现](https://github.com/larksuite/cli/blob/main/shortcuts/common/common.go)。
