# Yu+ v0.3.7

## 群聊按讨论与独立材料整理

Skill 改为先理解相邻发言及其上下文，再按连贯讨论/决策片段收录；不再默认逐条消息生成原始材料或对象。普通确认、系统通知、重复闲聊按实际情况留在监控队列。

- `monitor capture` 支持 `message_versions` 和可读 `title`，合并为一份 `chat_segment` 来源，保留原文、发言人、时间和定位；支持重试去重，所有引用成员仍参与监控复查。
- 独立文件、云文档和会议纪要实际读取并保存本地资产，保留飞书消息出处。同一材料的链接与本地内容保持关联。
- file/image key、传输标签、下载路径和运行日志保存在技术元数据或原始证据中，不进入 draft/review 业务简介。主 Skill、场景参考及中文审阅版同步。
- 群消息/片段不再显示不适用的文档远端检查提示。

本版不会自动改写或删除既有项目中的历史信源；清理已有噪声应按用户指示修改当前对象，并保留旧版本。

## 项目删除

新增 `project delete --project ID --base-version N --request-id REQUEST_ID --json`。N 来自 project show 的 metadata_version。

采用软删除：正常项目列表/页面隐藏，禁止业务写入，暂停本地监控并使租约失效；保留材料与历史，不清除共享文件池。`project list --include-deleted` 可查询保留项目。没有永久清除/恢复命令。

回执中的 scheduler_actions 需要 Agent 通过宿主工具同步处理；本地暂停不代表宿主任务已停止，共享任务保留其他项目范围。

## 升级与验证

数据库仍为 schema 3，无新增迁移。官网提示词已同步；沿用原数据目录，备份并停止旧服务，升级后重启。验证包括分组收录/重试/成员复查、文件加讨论的真实 CLI 链路、项目删除的隔离/版本校验/监控停用，以及安装包原位升级。真实群聊与宿主定时任务未执行。
