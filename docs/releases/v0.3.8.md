# Yu+ v0.3.8

监控群聊卡片支持折叠，在信息收集和整理与 Review 页面默认只显示标题、群数量及需关注提示，为项目正文留出空间。

- 点击“展开 / 收起”查看或隐藏详细状态、运行记录与操作 Prompt。
- 高度与箭头采用 300ms 过渡；内容保持挂载，连续点击可反向过渡，避免直接移除内容造成跳变。
- 同一页面会话中按项目保留展开状态，切换 draft / review 时保持一致。
- 支持键盘操作、展开状态播报；收起内容退出键盘焦点序列，遵循系统减少动态效果偏好。
- 无数据库迁移，现有项目与监控配置保持兼容。

验证：56 项前端与官网测试通过；Codex 内置浏览器验证折叠、展开、连续点击、键盘操作、场景切换和实际高度过渡；隔离环境从 v0.3.7 升级验证安装、数据保留、服务与前端资源。
