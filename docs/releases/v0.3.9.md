# Yu+ v0.3.9

长对象的标题栏现在会在滚动至顶部导航下方时吸顶，阅读子目时仍可看到对象名称、版本和复制引用入口。标题只在本对象范围内停留，到达对象边界后随卡片一起离开，后续对象自然接续。

- 信息收集的对象卡片及 Review 成果采用同样的吸顶行为。
- 采用浏览器原生 sticky 定位，无需滚动时重建标题或切换固定布局。
- 自动避让顶部导航；目录在窄正文布局中堆叠到上方时，按其实际高度避让。
- 保留现有版本切换、复制引用及来源详情交互，无数据库迁移。

验证：56 项前端与官网测试通过；Codex 内置浏览器验证对象中段吸顶、底部退出、下一对象接续、目录展开、检查器窄布局及 Review 标题；隔离环境从 v0.3.8 升级验证安装、数据保留、服务和前端资源。
