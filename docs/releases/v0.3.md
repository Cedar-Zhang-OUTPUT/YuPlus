# Yu+ v0.3

新增 D24「开放性问题」，将开放探索与具体客户澄清问答分开维护。

- D24 位于“判断与决定”，可保存议题、背景、影响、候选思路、跟进人、讨论状态、结论、来源及关联对象。没有答案不阻止信息收集或整理。
- 按问题用途分类，不按发言人或来源分类。主策、客户、会议或群聊中的探索议题归 D24；D15 客户 Q&A 保存具体澄清问答，包含客户提问与团队答复、团队向客户核实事实及客户回应。D15 可记录提问方和答复方。
- CLI、服务、目录、只读页面和正式 Skill 共用 24 类对象模型；同步中文审阅稿。中文稿仍不安装、不供 Agent 自动读取。
- R05 继续展示同一 D15；R01—R04 可按实际内容引用 D24。开放议题形成结论后，先更新相关 draft 和实际决策记录，再更新已有受影响 review。
- 群聊监控可用原有增量读取和幂等步骤保存 D24，开放性问题不再被要求写进客户 Q&A。

## 安装与升级

从[官网](https://cedar-zhang-output.github.io/YuPlus/)复制短提示词给 Agent，下载 `YuPlus-v0.3.tar.gz` 并验证 `SHA256SUMS.txt`。Python 包版本为 `0.3.0`，支持 macOS。

升级前备份、停止旧服务，沿用原应用/数据/Skill 目录安装，再启动。首次访问将 schema 1/2 升级到 schema 3，并在数据目录旁的 `数据目录名-migration-backups` 下保存完整迁移前备份。保留历史数据、对象身份、来源、版本与依赖，不自动搬迁旧 Q&A 内容。需要回退时使用旧版本和升级前备份恢复到新目录，不让旧程序操作已迁移的数据库。

对旧 Q&A 中明确误分类的内容，Agent 可按用户任务范围核对原文，保留来源和历史，通过 draft 修改重新归类，并更新已有受影响 review；不直接改历史版本或批量猜测分类。

## 验证范围

168 项 Python 测试、51 项前端/官网测试、95 项契约检查及两份 Skill 格式检查通过。覆盖旧库迁移和失败回滚、数据与依赖保留、完整备份恢复、跨项目引用拒绝、群聊幂等处理、D24 更新对 review 的因果约束。

隔离项目已跑通真实 CLI 的创建项目、收录材料、D15/D24 分类保存、review 准备与发布、修改 draft 后更新 review；Codex 内置浏览器验证 D24 目录与状态、来源追溯，以及 R05 只展示客户问答。未操作用户正式项目、真实群聊或定时任务。真实 Agent 的分类表现仍需项目使用验收。
