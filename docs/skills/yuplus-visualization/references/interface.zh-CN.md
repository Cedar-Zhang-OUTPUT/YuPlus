# 页面与控件指南

向用户说明时使用界面上的中文名称。桌面布局包含左侧导航、阅读区和按需打开的详情检查器。窄窗口会折叠导航并调整排布；触摸设备使用明确的导航/目录按钮，不依赖 hover。

## 项目与导航

项目列表支持搜索及空状态。通过身份确认目标，尤其是存在同名项目时。“新建项目”提供复制到 Agent 对话的文字，不是浏览器直接创建数据库的表单；Agent 按用户请求使用业务 CLI 创建项目。 提供“新建并提供文件”和“新建并监控飞书群”两个模板，行内文本框只用于准备复制文字，留空复制为 `______`。文件在 Agent 会话中附上；仅点击复制不会创建项目或定时监控。

项目内有“项目信息”“策划文档”“原始资料”“修改与确认记录”；信息分类说明页解释支持的类型。导航按钮展开或收起侧栏。页脚显示页面刷新时间和“刷新页面”，该时间不是远端来源检查时间。历史页显示已保存的变更和决定，不会因为点击按钮就生成审核确认或导出记录。

“信息分类说明”从“项目信息”标题旁的问号进入。时间项 `owners` 可为空、单人或多人；甘特图标题后用灰色小字展示已保存姓名。Q&A 分别显示“提问人”“回答方”，未知显示“未明确”，不能根据跟进人推断双方身份。

## 项目信息：draft

阅读区按主题组织 23 类业务对象。它们是可用类别，不要求项目必须填满 23 类。“全部 25 类”/“只看有内容”切换目录筛选。点击目录项滚动至相应对象；滚动也会更新选中项。

“信息目录”初始收起。hover 打开悬浮预览，不改变阅读区布局比例；移出或选中目标后自动关闭。点击“展开信息目录”或“固定展开信息目录”后常驻展开并调整布局，此时点目录项不会自动收起。“收起信息目录”可将其关闭。窄窗口中向下展开；触摸和键盘也使用这些明确按钮。

卡片显示版本和更新时间。点击“历史版本”打开 draft 版本菜单，选择“历史版本 v…”或“当前版本 v…”。上下方向键、Home/End 在选项间移动；Enter/空格激活聚焦按钮；Escape 关闭。历史选择只改变阅读内容，不更改保存的当前版本。历史卡片会提示，并提供返回当前的方式。

支持折叠的长正文超过三行后收起。点击/轻触正文，或聚焦后按 Enter/空格，可展开或折叠。短正文、内部已有交互元素的文本块可能不支持折叠。选择文本不会触发折叠；可用宽度改变时重新测量。

hover 或键盘聚焦彩色条目卡片，可看到竖排信息性质，如“原文信息”“策划补充”“建议方向”“当前采用”。它解释已保存的信息性质，不是状态变更，也不是独立编辑入口；颜色边缘展开不改变正文宽度。

结构化金额按整数最小货币单位和币种展示，正文识别到的金额亮红色。高亮只是展示规则，不是校验，也不应因此修改原文或插入 HTML。未知金额仍保留未知。

D13 甘特图读取已保存的结构化 start/end，不解析正文里的日期。有具体日历节点或完整区间的事项都应进入图表，不连续的安排分别存成 D13 条目；TBC 或建议日期仍可画入图表并保留暂定说明与证据。只有无具体日期的时间说明保留为文字卡片。漏项时通过业务 Skill/CLI 检查并修正 D13 字段后刷新，不修改页面数据、不编造日期。时间轴支持天和分钟精度、时间节点和区间。日期只有天时，不凭空补午夜或时区。展开里程碑可查看详情。交付时间线按轮次组织、引用时间节点；参考日期不能自动解释为已确认截止时间。

Q&A 卡片同时展示问题和回答，未回答保持待答复，不适用保留解释。证据通过统一“依据”来源行展示。

D25“开放性问题”位于“判断与决定”，按已记录内容展示议题、背景、影响、候选思路、讨论状态、结论、来源和关联对象。状态为待讨论 / 探索中 / 已有结论 / 暂缓 / 已关闭。它与客户澄清问答分开维护；R01—R03 可引用，R05 仍只展示 D18。

## draft 与 review 共用的项目群更新

项目行显示“监控 N 个群”及需要关注的数量。“项目信息”和“策划文档”都有同一个“项目群更新”卡片，只显示当前项目；旧服务没有监控数据时显示空状态。受支持的已保存群 AppLink 在新标签页打开，打开群不会替它配置监控。

每个群显示指定间隔、启用/暂停/待接通状态、**全部可访问历史**的收集情况、“已拉取至”“最近检查”“最近同步完成”“最近保存结果”、待处理消息及错误。提供数据时，“已记录澄清消息”统计历史上已转成澄清处置的消息，不代表当前尚未回答的 D18 问题。历史收集完成只说明拉取窗口完整，不说明所有消息均已采用，也不包括不可访问历史。检查时间可能记录失败尝试，要结合错误与完成结果看。

“已保存调度绑定回执”只反映已保存宿主回执；回执过旧显示“调度状态待核验”，逾期显示“尚未收到本轮结果”，都不能证明 Agent 此刻正在运行。不编造实时阅读/进度状态。“查看已保存运行记录”展开服务实际提供的记录；“拉取未完成”/“处理未完成”/“已完成”只描述已保存阶段。没有明细时复制查看记录指令，不声称从未运行。

“复制立即同步指令”“复制暂停指令”/“复制恢复指令”“复制调整间隔指令”“复制解除绑定指令”“复制查看记录指令”只复制绑定真实数据目录、项目、监控及配置版本的意图，不执行业务或调度更改。将所需指令 发给 Agent 会话后执行；调整间隔还要提供期望分钟数。写入前重读当前配置，完成后刷新页面查看结果。

## 原文、快照与真实文件

“依据”行有两个不同动作：有规范原文地址时，点击保存的来源标题在新标签页打开原文；本地来源的标题在新标签页打开所引用版本的唯一可用原件；没有可唯一定位的原件时，打开该快照详情。“查看引用”打开该卡片实际引用的已保存快照。打开原文不等于导入原文最新版本。

“来源详情”包含来源身份/URL、保存的远端检查信息、已保存快照版本、所选快照正文和文件、反向引用。点击快照的“查看”读取其保存内容。“本地主快照”只是本地所选主版本，不是远端最新证明。正文可能为完整内容、明确标注的节选，也可能没有文本而只有附件。反向引用列出当前 draft 条目对该来源各快照的引用，不是所有历史引用的完整清单。调查历史 Review 时应沿其 lineage 读取确切旧依据。

已登记且可用的图片可以直接预览；音视频使用浏览器播放控件。“打开文件”在新标签页打开可用资产。PDF 显示、媒体编解码/播放、保存/下载取决于浏览器和格式，不支持的格式可能转为下载。“下载”按已记录的原文件名保存文件池中的附件，包括口述来源的附件和恢复到文件池的材料；下载的是已保存原字节，不是重新导出的提取文本。不能把图标或元数据说成已渲染 PDF。文本/Markdown 快照展示不是完整保真的 Office 文档查看器。

“在 Finder 中显示”只在 macOS 服务确认外部登记原文件路径未变、内容可用时出现。内部哈希命名副本和恢复到文件池的文件显示“下载”；其他平台的可用文件也使用下载。依据资产保存方式及可用性判断，不依据本地、口述或飞书来源分类。请求只使用项目、快照和资产 ID，由服务端解析路径；不可传任意路径或 shell 命令。缺失或变化不删除来源关系。演示占位内容不能冒充可下载或定位的真实原件。

## 案例库源

“浏览”下的“案例库”打开 `#/libraries`，按 Official 内置来源和 Personal 个人来源展示可搜索的双列列表。所有预置源及新增 Personal 源默认启用。“添加源”填写名称、类型和有效网站／飞书文件夹链接；“移除”直接关闭使用，来源仍显示，点击“添加”恢复原登记。设置由本地服务保存，有保存中和错误反馈，不再需要复制 Prompt。手动关闭的源在重启、升级后保持关闭。标题在新标签页打开原站点。项目内容继续只读；启用的文件夹由飞书 CLI、网站由浏览器／网页工具按需查找，页面不声称已读取或缓存内容。模拟预览禁用写入。

## 全局头像
悬停、聚焦或点击左上角头像，显示「更改头像」。按钮复制带当前数据目录的提示词；在 Codex 附图并按 Yu+ 头像参考执行。页面不上传或写入图片。CLI 更改后刷新页面，Escape 可关闭菜单。

## 案例分析

当前项目中的「案例分析」打开独立研究视图。历史下拉显示 v1/v2 与精确到秒的创建/更新时间。「复制开始分析指令」明确请求**新开研究**，仅复制不创建版本。补充内容、修改说明和飞书直接编辑仍属于当前轮次。执行时读取业务 Skill 的案例分析参考，不自动写入 draft/review。

刷新左侧「打开飞书画板 ↗」在新标签页打开所选版本已核验的画板链接，保留锚点，缺省兼容文档链接。缺少链接时禁用，切换版本同步切换目标，不从示例图编造真实链接。预览刷新由程序负责。CLI 保存真实研究轮次，本地服务每 60 秒获取当前可见画板。隐藏页面停止轮询，失败保留旧图，认证或权限失败暂停轮询。demo 版本仍明确为示意。新建或刚关联的研究需刷新页面以重读历史。


策划文档页常驻「打开飞书协作文档」链接，新标签页打开。协作卡显示已保存的检查/同步状态及记录；无绑定时提示在 Codex 开始整理。没有单独复制导出入口。程序检查与 Agent 整理分别运行，不能从页面刷新时间推断同步完成。

来源行展示检索方向，可展开“怎么用”查看使用建议；两者都可搜索。Personal 表单支持选填“适合找什么”和“怎么用”，已启用源可点“编辑说明”修改或清空。保存后 CLI 读取相同数据；已关闭源先重新添加再编辑。
