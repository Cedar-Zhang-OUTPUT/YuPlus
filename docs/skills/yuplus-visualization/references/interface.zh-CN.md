# 页面与控件指南

向用户说明时使用界面上的中文名称。桌面布局包含左侧导航、阅读区和按需打开的详情检查器。窄窗口会折叠导航并调整排布；触摸设备使用明确的导航/目录按钮，不依赖 hover。

## 项目与导航

项目列表支持搜索及空状态。通过身份确认目标，尤其是存在同名项目时。“新建项目”提供复制到 Agent 对话的文字，不是浏览器直接创建数据库的表单；Agent 按用户请求使用业务 CLI 创建项目。

项目内有“信息收集”“整理与Review”“原始材料”“变更与决定记录”；对象说明页解释支持的类型。导航按钮展开或收起侧栏。页脚显示页面刷新时间和“刷新页面”，该时间不是远端来源检查时间。历史页显示已保存的变更和决定，不会因为点击按钮就生成审核确认或导出记录。

## 信息收集：draft

阅读区按主题组织 23 类业务对象。它们是可用类别，不要求项目必须填满 23 类。“全部 23 类”/“只看有内容”切换目录筛选。点击目录项滚动至相应对象；滚动也会更新选中项。

“对象目录”初始收起。hover 打开悬浮预览，不改变阅读区布局比例；移出或选中目标后自动关闭。点击“展开对象目录”或“固定展开对象目录”后常驻展开并调整布局，此时点目录项不会自动收起。“收起对象目录”可将其关闭。窄窗口中向下展开；触摸和键盘也使用这些明确按钮。

卡片显示版本和更新时间。点击“历史版本”打开 draft 版本菜单，选择“历史版本 v…”或“当前版本 v…”。上下方向键、Home/End 在选项间移动；Enter/空格激活聚焦按钮；Escape 关闭。历史选择只改变阅读内容，不更改保存的当前版本。历史卡片会提示，并提供返回当前的方式。

支持折叠的长正文超过三行后收起。点击/轻触正文，或聚焦后按 Enter/空格，可展开或折叠。短正文、内部已有交互元素的文本块可能不支持折叠。选择文本不会触发折叠；可用宽度改变时重新测量。

hover 或键盘聚焦彩色条目卡片，可看到竖排信息性质，如“原文陈述”“用户补充”“建议”“采用决定”。它解释已保存的信息性质，不是状态变更，也不是独立编辑入口；颜色边缘展开不改变正文宽度。

结构化金额按整数最小货币单位和币种展示，正文识别到的金额亮红色。高亮只是展示规则，不是校验，也不应因此修改原文或插入 HTML。未知金额仍保留未知。

时间轴支持天和分钟精度、时间节点和区间。日期只有天时，不凭空补午夜或时区。展开里程碑可查看详情。交付时间线按轮次组织、引用时间节点；参考日期不能自动解释为已确认截止时间。

Q&A 卡片同时展示问题和回答，未回答保持待答复，不适用保留解释。证据通过统一“依据”来源行展示。

## 整理与 Review

| 编号 | 界面成果 | 身份规则 |
| --- | --- | --- |
| R01 | 主策 Debrief | 已保存 Review 对象 |
| R02 | 推进要素 | 已保存 Review 对象 |
| R03 | 创意审查结果 | 已保存 Review 对象 |
| R04 | 内外部创作者 Brief | 可同时有多个创作者/轮次实例 |
| R05 | 客户 Q&A | 同一 D15 draft Q&A 的视图，不另存重复 Review |

先选成果类型，Brief 有多个实例时再选实例。通过版本区域及其“查看”按钮读取 Review 历史版，历史阅读有明确标记。段落操作为“完整追溯路径”“复制引用”；有变化的段落还有黄色“查看差异”。橙色依据变化提示提供“查看受影响段落”“复制更新 Prompt”。标题处“复制飞书导出 Prompt”覆盖整个项目，与当前选中卡片无关。范围及执行流程见 [Review 操作](review-actions.zh-CN.md)。

## 原文、快照与真实文件

“依据”行有两个不同动作：有规范原文地址时，点击保存的来源标题在新标签页打开原文；本地来源没有 URL 时，标题打开来源详情。“查看引用”打开该卡片实际引用的已保存快照。打开原文不等于导入原文最新版本。

“来源详情”包含来源身份/URL、保存的远端检查信息、已保存快照版本、所选快照正文和文件、反向引用。点击快照的“查看”读取其保存内容。“本地主快照”只是本地所选主版本，不是远端最新证明。正文可能为完整内容、明确标注的节选，也可能没有文本而只有附件。反向引用列出当前 draft 条目对该来源各快照的引用，不是所有历史引用的完整清单。调查历史 Review 时应沿其 lineage 读取确切旧依据。

已登记且可用的图片可以直接预览；音视频使用浏览器播放控件。“打开文件”在新标签页打开可用资产。PDF 显示、媒体编解码/播放、保存/下载取决于浏览器和格式，不支持的格式可能转为下载。不能把图标或元数据说成已渲染 PDF，也不能在没有时声称存在专门“下载”按钮。浏览器支持时，可在打开文件后使用保存/下载功能。文本/Markdown 快照展示不是完整保真的 Office 文档查看器。

“在 Finder 中显示”只在 macOS 本机服务报告支持且登记文件可用时出现，用于选中该已保存文件，不下载远端原件。请求使用项目、快照和资产 ID，服务端解析路径；不能建议把任意路径或 shell 命令传给定位接口。文件缺失、变化或不可用，不会删除其来源关系记录。显式演示模式定位的可能是生成的示例文本，不是真实原件。
