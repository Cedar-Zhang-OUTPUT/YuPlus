# 按实际故障处理

| 现象 | 检查和下一步 |
| --- | --- |
| 地址打不开 | 检查已知会话/监听，在实际端口检查 `/api/health`。不存在时启动目标真实服务，不为占用 7801 而终止其他进程。 |
| 看到了演示项目 | 健康模式为 `demo` 或打开了错误标签。找到/启动绑定正确数据目录的真实服务，打开返回地址，不通过导入示例“修复”真实空项目。 |
| 服务健康但项目不对或为空 | 对照 health 的 `data_dir` 与已确定目录，再列项目身份。同名项目可能存在；误选新目录不代表数据丢失。 |
| “无法读取项目内容” | 查看错误及健康/API 状态，核对目录、访问权限和安装版本；修复后“重新读取”。读取失败不等于空项目，不应降级显示其他项目缓存。 |
| “项目不存在”或找不到对象 | 核对该服务中的 ID 和项目归属，使用真实返回值，不用截图/示例 ID。不要为让旧 URL 可用而创建重复对象。 |
| CLI 保存内容没出现 | 检查成功回执和数据目录，点“刷新页面”。检查是否选中了历史版，必要时返回当前。切换路由可能复用已加载数据。 |
| 版本菜单或媒体不工作 | 版本菜单使用原生 popover，媒体依赖浏览器格式/编解码支持。换兼容浏览器，或通过支持工具读取确切保存版本/资产；不声称所有浏览器支持所有文件。 |
| “无法复制” | 剪贴板访问失败。重试可见按钮，检查浏览器权限/上下文。必要时根据已核验身份整理等效请求，或协助复制可读文字；不能说复制成功。 |
| 没有原文链接/标题 | 来源可能是本地材料，或只保存了地址、标题尚未取得。使用快照和已保存身份，不编造远端标题/地址。 |
| 文件缺失或内容变化 | 检查登记资产可用性和所选快照。外部文件可能移动、删除或哈希改变。保留历史来源，使用业务导入/追加流程保存新版，不将其冒充旧资产。 |
| Finder 按钮没有出现或失败 | 需要 macOS、服务支持及路径和内容未变的外部登记原文件。文件池副本、恢复文件及其他平台使用“下载”。移动文件后重新检查，不绕过为任意路径定位。 |
| 缺少依据/无法比较 | 重新读取确切引用版本和证据。unknown 不等于未变化或删除；不制造替代关系，也不声称已同步。 |
| 导出没有生成文档 | 浏览器只复制 Prompt，本地 bundle 只写文件。实际执行还需要导出请求、飞书 CLI/认证、新建写入和回读；保留准备文件，如实说明具体授权、登录或权限失败。 |

必要时用可用的浏览器检查工具核实出错控件，区分实际观察与源码推断。设计交接截图不能证明当前真实服务、附件、剪贴板或飞书导出已经成功。
