# 官网与 v0.1 发布验证

## 交付内容

独立静态官网放在 `website/`，GitHub Pages 只发布这一目录。原有应用 UI 与业务服务不改动。首页介绍本地协作、draft 收集和 review 整理，主要操作是复制完整安装提示词。提示词固定下载官方 v0.1 安装包和校验文件，沿用已有安装及正式数据，检查飞书，并指导 Agent 启动真实服务。

v0.1 固定应用提交 `3db434a`；发布附件为该提交的 Git 归档及 SHA-256 清单，不含未跟踪文件或任何运行数据。包内 Python 包版本采用规范形式 `0.1.0`，GitHub Release/tag 为用户指定的 `v0.1`。

## 视觉与交互

设计基于两张独立 Image Gen 概念图：首屏与工作方式/安装区。使用纸白 `#f5f3ed`、深墨 `#20221f`、黄绿色 `#d9f267`，原生 HTML 文案与资料关系图，无第三方字体或图片依赖。

通过 Codex 内置浏览器检验实际页面，以 1440×1000 桌面视口和整页截图对照概念，并以 view_image 检查概念及实现截图；同时检查 390px、320px 手机布局。未使用 Playwright Chromium 替代浏览器。

| 对照项 | 结果与处理 |
| --- | --- |
| 首屏文案、导航和 CTA | 保留概念规定的标题、说明、三个导航和复制按钮，无新加眉题或宣传数字。 |
| 布局与分区 | 保留左文案/右资料层叠、三项特点、两场景说明、深色安装面板和页脚顺序。 |
| 字体 | 使用系统中文字体，字形与概念生成字体存在有意差异；字号按实际可读性及窄屏排布调整。 |
| 配色与容器 | 保留纸白、深墨和黄绿，细线分隔、少量圆角，无增加卡片网格或光晕。 |
| 图标与关系图 | 同一组 SVG 线性文件/文件夹/箭头图标；资料图是静态关系示意，未伪装为可操作的真实项目。 |
| 手机排布 | 单列重排，无横向溢出；发现说明与示意图底部重叠后增加画布高度，复验不再重叠。 |

实际点击首屏按钮，浏览器剪贴板内容与完整提示词逐字相同。导航与展开操作正常，浏览器无控制台错误。复制失败的展开/选中回退由自动测试验证。三项 `node --test tests/test_website.mjs` 全部通过，`node --check website/site.js` 通过。
