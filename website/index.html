工作方式

从一份材料开始，
让每一步都有依据。

  1. 01

    收集信息，写入 draft

    飞书文档、本地文件、你的补充。Agent 读取材料，把信息放进对应对象，保留来源。

  2. 02

    整理内容，交给你 review

    基于已有对象组织成果。你随时可以补充或修改，Agent 先更新 draft，再同步 review。

不必等资料齐全。随时开始整理，也随时回到收集。

下一步，
交给你的 Agent。

复制这段提示词，发给 Codex。它会下载 Yu+，检查环境，并打开你的本地工作空间。

安装并开始使用 Yu+

  1. 请帮我安装并启动 Yu+ v0.1。
  2. 从官方 GitHub Release 下载并验证安装包。
  3. 检查本地环境，运行统一安装入口。
  4. 安装 Yu+ 与两份 Codex Skill。
  5. 沿用正式数据目录，不覆盖已有项目。
  6. 检查飞书 CLI；缺少认证时明确提示。
  7. 启动服务，在 Codex 中打开实际地址。
  8. 先询问我的项目名称，不导入演示材料。
