    它是什么

    创意可以大胆，
    理解必须具体。

    从品牌想表达什么，到人们真正关心什么；从一个初步想法，到可以被看见、被感受的体验。Yu+ 帮助你整理资料、分析参考、记录判断，为创意提供更具体的依据。

    1. 01

      读懂需求

      从客户的需求说明和沟通中，梳理品牌目标、真实受众与工作边界。

    2. 02

      看懂参考

      分析案例如何回应它的任务，提炼可借鉴的方法与不适用的条件。

    3. 03

      留下判断

      把原始依据、团队建议与当前采用的方向分开记录，让讨论有迹可循。

    4. 04

      与团队协作

      把项目理解和工作要求整理成策划文档，在反馈中继续完善。

    工作方式

    从一份 Brief 开始，
    也可以从一个想法开始。

    客户需求、会议记录、参考资料，或还没想完整的判断，都可以成为起点。继续补充，或先整理一版，你可以随时选择。

    添加资料

    原始资料

    客户 Brief、会议记录、参考文件或口头补充，都可以发给 Codex；整理后的内容保留原始出处。

    →

    理解项目

    项目信息

    这次创意，要回应什么？梳理品牌目标、受众、场景、预算与交付要求，区分原始需求、团队判断和待确认的问题。

    →

    整理文档

    策划文档

    整理主策 Debrief（项目理解与工作边界）、项目推进安排、创意评审记录和客户问答，供团队阅读与讨论。

    告诉 Codex 哪里变了 → 更新相关项目信息 → 调整受影响的策划文档，并保留修改依据。

    每条信息都标明性质

    客户原文、团队判断与已采用的决定分别标明。文字说明性质，颜色辅助识别。

    • 原文信息

      可以回到原文定位。

    • 策划补充

      主策补充，不是客户原文。

    • 转述信息

      经他人转述，可能有偏差。

    • 待验证判断

      尚未确认，不作事实依据。

    • 建议方向

      是提议，不是正式决定。

    • 当前采用

      保留决定者、记录时间与依据；不等同于客户确认。

    继续推进项目

    为真实的比稿节奏而做。

    ⌕

    案例分析｜看懂一个创意为什么成立。

    从品牌背景、创意策略、叙事和视觉表达中，分析案例如何回应它的任务。查找你登记的案例库与公开网络，提炼对当前项目有启发的方法，也说明需要重新思考的条件。

    ⧉

    案例参考板｜让参考便于讨论。

    将入选案例的真实图片、分析与原始出处整理到飞书画板。可以继续补图、修改说明，也可以开启新一轮分析，保留之前的版本。

    ≣

    策划文档｜让团队理解你的判断。

    把项目背景、受众、交付边界与推进安排整理成团队可以使用的文档。补充资料或提出修改后，更新受影响的内容，保留调整依据。

    ◷

    跟进项目讨论

    客户补充了什么，团队决定了什么，还有哪些问题没谈清楚。指定飞书项目群后，按约定间隔整理新讨论，方便及时判断和调整。

    ↗

    整理成飞书文档

    将当前策划文档配上必要的图片、附件和原文链接，便于团队阅读与讨论。进入策划文档阶段时创建或复用飞书文档。接通定时任务后，整理团队的新修改；遇到冲突先与你确认，保留调整依据。

    ⧉

    保留每一步依据

    回看原始资料、修改与确认记录，理解一个判断从何而来。升级前备份现有项目，按原有数据位置继续工作。

    • 资料有出处从整理后的内容回到原始资料。
    • 判断有区别团队采用的方向，不替代客户确认。
    • 随时可补充不用等资料齐全再开始整理。
    • 在对话中修改告诉 Codex 你的想法，在 Yu+ 查看结果。

    案例参考板用于讨论与比较参考。Moodboard（概念情绪板）则通过图片之间的关系表达核心概念、情绪与体验意图；这里不将案例图集等同于已经完成的 Moodboard。

    请阅读 agent-install.md，按指南帮我安装或升级到 Yu+ v0.3.26 并启动，保留已有项目数据。

    安装、数据保存与授权说明
    1. 从官方 GitHub Release 下载并校验 SHA‑256。
    2. 升级前先备份已有数据，沿用原数据目录。
    3. 运行统一安装入口，安装两份 Codex Skill。
    4. 检查飞书 CLI 认证，缺失时明确告知。
    5. 启动服务，在 Codex 中打开实际本地地址。
    6. 询问你的项目名称，不导入演示材料。
